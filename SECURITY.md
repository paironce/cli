# Security policy

## Reporting a vulnerability

Email **security@paironce.com**. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and what an attacker gains. We answer within 3 working days, agree a fix and
disclosure date with you (normally within 90 days), and credit you in the advisory unless you prefer otherwise.

## Scope

This repository is the command-line tool and MCP server, published on npm as `paironce`. Reports about the protocol, the
core library (`@paironce/core`) and the production service at paironce.com are welcome at the same address. The full
policy, with what is out of scope and the safe harbour for good-faith research, is in
[paironce/security](https://github.com/paironce/security/blob/main/SECURITY.md).

## Releases

Each version is a GitHub release in this repository and is published to npm and the MCP registry by this repository's
workflows. Changes in each version are in the [releases](https://github.com/paironce/cli/releases).
